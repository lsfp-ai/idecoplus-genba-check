# iDeCo+ と役員 — 2つの別々の論点

2026-08-14 確定。**第2章の結論は加藤 博の判断**（CFP®／企業年金管理士／1級DCプランナー／

**この2つは完全に別の論点。混ぜて論じない。**

| | 問い | 章 |
|---|---|---|
| ① | 役員を iDeCo+ の**対象から外せる**か | 第1章 |

---

## 第1章　役員を対象から外せるか　→ **外せない**

### 結論

**「役員だから」という理由で、会社が拠出対象から外すことはできない。**

### 根拠（国民年金基金連合会「中小事業主掛金納付制度の手引き」・原文）

【検討事項5】
> 「一定の職種」又は「一定の勤続期間」以外の資格で中小事業主掛金の拠出対象者を限定することは、
> 特定の者に不当に差別的であるとみなされるため、**中小事業主掛金納付制度の導入は認められません。**

【検討事項3】（注1）
> 「職種」とは、総合職、一般職、営業職、事務職などを指し、**部長、課長などの役職のことではありません。**

### ただし、次の3つは別

| | 内容 | 根拠 |
|---|---|---|
| **額を分ける** | できる。労働条件が異なるなど合理的な理由があれば区分できる | 同手引き【検討事項4】（注） |
| **本人が加入していない** | 対象にならない。**不当に差別的な取扱いにはならない** | 同【検討事項5】 |
| **事業主払込でない** | 対象にならない | 確定拠出年金法68条の2第1項 |

## 第2章　役員に出した掛金は、会社法上の報酬等か　→ **通常は当たらない。決議は不要**

### 結論（先に置く）

**iDeCo+ の中小事業主掛金は、役員の職務執行の対価として支給する役員報酬ではない。**

厚生年金被保険者である iDeCo 加入者の老後所得を支援するため、確定拠出年金法に基づいて
事業主が拠出する制度上の掛金である。

**従業員と共通する加入資格と掛金基準に基づいて役員にも拠出する通常の制度設計では、
会社法361条1項の「報酬等」には該当しない。したがって株主総会決議は不要と整理する。**

### ここでいう「通常の制度設計」

- 厚生年金被保険者である加入者を対象とする
- 従業員と役員に**共通する資格基準**を使う
- **共通する掛金基準**を使う
- **役位や業績の対価として掛金額を決めない**
- **役員だけを特別に優遇しない**

### なぜ報酬等ではないのか（判断の軸）

会社法361条1項の要件は「**取締役の職務執行の対価として株式会社から受ける財産上の利益**」。

iDeCo+ の掛金が支給される原因は、

- ❌ 取締役として職務を執行したから
- ⭕ **iDeCo+ の対象となる厚生年金被保険者であり、制度上の要件を満たしたから**

役員の経営判断・営業成績・役位・職責に対する対価ではない。**だから「職務執行の対価」に当たらない。**

### 🚫 使ってはいけない論法

**「税務上の給与ではない。だから会社法上も報酬等ではない」は論証になっていない。**

税務（法人税法施行令135条4号の損金算入、所得税法施行令64条5号の給与所得非算入）と、
会社法361条1項は**別の法域**。税の結論をそのまま持ち込まない。

（同型の誤りは社会保険でも起きる。memory `reference_dc_contribution_social_insurance_remuneration`
「税の結論を社会保険へ流用する」を参照）

### 例外（職務執行の対価と評価されうる設計）

- **役員だけを対象**とする設計
- **役員だけ掛金を増額**する設計
- **役位や業績に連動**して掛金を決める設計

この場合は、会社法361条に基づく株主総会決議の要否を**個別に確認する**。

### どこまで断定できるか（正直に区別する）

- iDeCo+ の役員分について「**会社法361条の報酬等に該当しない**」と直接書いた法令・行政通知・
  国税庁文書・最高裁判例は、**確認できていない**。
- したがって「**法令で明確に報酬ではないと決まっている**」とは書かない。
- 一方で、直接書いた資料が無いことを理由に「**不明**」で止める必要もない。
  **会社法361条1項の要件に当てはめれば、通常の iDeCo+ 掛金は職務執行の対価ではない。**

**文書の立場＝一次資料に直接の明記はない。しかし条文の要件に当てはめると報酬等に当たらない。
したがって通常は株主総会決議を必要としない。**

### 参考（使用人兼務役員）

最判昭和60年3月26日は、使用人としての給与体系が明確に確立している場合に、使用人給与と
取締役報酬を区別できるとする。**ただし DC 掛金について判断したものではない。**
使用人兼務役員をどちらの区分に入れるかは、先に決めて社労士へ確認する（教材 No.125）。
