# iDeCo+ 現場チェック

金融アドバイザー向けの確認テスト。**社長・従業員との商談で実際に飛んでくる場面**を出して、「この発言を、いま顧客の前で言ってよいか」を判定します。

**制作＝株式会社LSFP**

---

## これは何か

- **45問の問題銀行から、毎回20問**を出題（5〜8分）
- **認定も資格も合否も出しません**
- 返すのは「**本番なら顧客に届いていたNG話法が何件あったか**」
- すべて **2026年12月1日施行の改正後**のルールで出題

## なぜ「言ってよいか」を問うのか

現場で起きる問題は「知らない」ではなく、**「知らないのに答えてしまう」**です。

だから3段で問います。

1. **この発言を、いま顧客の前で言ってよいか**（言ってよい／言ってはいけない）
2. 言ってはいけないなら、**なぜか**
   ① 内容が事実として誤っている
   ② 断定的判断の提供にあたる
   ③ 自分が答えてよい範囲を超えている
   ④ 内容は誤りではないが、条件次第で変わるので、その場では言い切れない
   （複数あてはまるときは **①＞②＞③④** の重い方）
3. **では、何と言えばよいか**

## 「全部『言ってはいけない』」では通りません

全部を「言ってはいけない」にすれば危ない発言はゼロになります。そうならないよう、**言い切ってよい場面を毎回6問**混ぜてあります。

結果は2軸で返します。

- **NG話法を言わずに済んだ** … n/8
- **言い切るべき場面で、言い切れた** … n/6

後者が低い人には「**持ち帰りが多すぎます**」と出ます。調べれば分かる事実まで持ち帰ると、社長からは「分かっていない人」に見えるからです。

## 使い方

`index.html` をブラウザで開くだけです。

- **単一HTMLファイル**。ビルド不要
- **ログイン不要**
- **記録は端末の中だけ**（localStorage も使っていません。ページを閉じれば消えます）
- **外部通信ゼロ**。どこにもデータを送りません

## 根拠について

全問に根拠を表示しています。

- **45問中35問**が、法令の条番号まで特定した一次情報（e-Gov法令検索・官公庁の公表資料）
- 制作者の考え方にもとづくものは「**制作者（株式会社LSFP）の考え方**」と明示
- 出典が特定できなかったものは、**その旨を正直に表示**
